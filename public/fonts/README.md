# Inter fonts

Vendored from @fontsource/inter 5.3.0 (Inter, https://github.com/rsms/inter).
The SIL Open Font License is preserved in OFL.txt.
WOFF2 files serve the interface; the Cyrillic WOFF serves the static Open Graph renderer.
No external font request is required for build or runtime.
The two digits in app/icon.svg are outlines from Inter Bold, so PNG generation does not depend on an installed system font.
