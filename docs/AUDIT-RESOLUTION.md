## Швидкодія та ресурси

Порівняння виконане локально однаковим Chromium-скриптом, viewport 390x844, шість послідовних перемикань року, із очікуванням двох animation frames. Це лабораторний час повного сценарію, а не польовий INP чи SLA.

| Режим | До, медіана | Після, медіана |
|---|---:|---:|
| Звичайний CPU | 150 мс | 101 мс |
| CPU slowdown x4 | 809 мс | 334 мс |

На CPU x4 окремі довгі задачі залишаються; їх усунення повністю не заявляється. JS зафіксованого тестового завантаження зріс приблизно з 202 до 213 kB compressed після оновлення runtime-залежностей, хоча робота при зміні року скоротилась.

Під час повного браузерного прогону контейнер залишався healthy, працював як nextjs/UID 1001, без OOM або відмов виділення пам’яті. Зафіксований пік cgroup - близько 118 MiB. Додатково перевірено 100 HTTP-запитів до головної/privacy/terms із concurrency 5: 0 HTTP-помилок. Це контрольний локальний прогін, не доказ місткості production під довільним навантаженням.
